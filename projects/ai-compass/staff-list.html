Staff list

The staff list is everyone who should take the assessment. Each person needs only a name and an email address. They need no account or password: each one gets a link by email.

Open it from Staff list in the menu on the left. The people are in the People section, under the box that says whether the assessment is open. You can add and change people whether the assessment is open or not.

Add one person

  1. In People, press Add a person.
  2. Type their Name and Email.
  3. Press Add person. You see “Saved”, and they appear on the list as Not sent.

Nothing is emailed when you add someone. You send the link later, from the same page (see Sending the link).

If you see “That email address is already on the list.”, that person is already there (perhaps under another name, or among the removed people; see Taking someone off the list).

Add many people from a file

If you have your staff in a spreadsheet, save it as a CSV file and add everyone at once.

What the file needs

One person on each row: their name, then their email address.

NameEmail
Pat Examplepat@example.com
Sam Samplesam@example.com
  • A heading row is optional.
  • Separate First Name and Last Name columns work too.
  • Other columns (phone, role and so on) are ignored, and the columns can be in any order if there is a heading row.
  • Commas, semicolons or tabs between columns all work.
  • An Excel workbook (.xlsx) will not work. In Excel choose File, Save As, pick “CSV (Comma delimited)”, and use the file it saves.
  • A file can have up to 2,000 rows, and a list holds up to 500 people.

Inside the app, Download an example file gives you a file to fill in.

Steps

  1. In People, press Add from a file.
  2. Press Choose a file and pick your CSV file. Or paste the list into the box under “Or paste the list here” and press Check the list.
  3. AI Compass reads the file and shows you, row by row, what will happen. Nobody is added yet.
  4. Look over the rows. Rows that cannot be added are shown first, with the reason.
  5. Press Add N people. You see “Added N people to the list”. Press Back instead if you want to fix the file first.

Nothing is emailed yet. You send the assessment from the list afterwards.

What each row can say

Row saysWhat it means
Will be addedA new person. They go on the list.
Goes back on the listSomeone you took off the list earlier. They go back on.
Already on the listThat email address is already there. Nothing changes for them, so adding the same file twice is safe.
No email addressThe row has no email address. It is skipped.
The email address does not look rightProbably a typo. It is skipped; fix it in the file or add the person by hand.
No nameThe row has an email address but no name. It is skipped.
The name is too longOver 200 characters. It is skipped.
This address is in the file more than onceA repeat of an earlier row. Only the first one is used.

If the whole file cannot be used, you see one of these instead: “No people were found in that file. It needs a name and an email address on each row.”, “That file has more than 2000 rows.”, or “A list holds up to 500 people, and this file would take it past that.”

Changing someone’s name or email

  1. Find the person on the list and press Edit on their row.
  2. Change their Name or Email.
  3. Press Save.

If you change someone’s email address, any link sent to the old address stops working. Send them the link again so it goes to the new address.

Taking someone off the list

Use this when someone has left, or was added by mistake.

  1. Press Edit on their row.
  2. Untick On the list.
  3. Press Save.

They get no more links, and a personal link they already have stops working. Anything they already answered stays in the results.

Putting someone back

People you have taken off are listed under Show N removed people below the list.

  1. Press Show N removed people.
  2. Press Edit next to the person.
  3. Tick On the list and press Save.

Adding them again from a file also puts them back.

What the status column means

StatusMeaning
Not sentThey have not been emailed the link yet.
Link sentThey were emailed the link, and when.
AnsweredTracked assessments only: they have sent their answers, and on what day. An anonymous assessment never shows who answered.

Above the list, a line counts the people on the list, how many were sent the link, and (for a tracked assessment) how many have answered. See Anonymous or tracked for the difference.
